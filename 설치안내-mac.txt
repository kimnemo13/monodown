monoDown 설치 안내 (Mac)
========================

1. 이 압축 파일을 통째로 풉니다. (monoDown 폴더가 생깁니다)

2. 터미널을 엽니다. (⌘+Space → "터미널" 검색)

3. 터미널에  bash  를 입력하고 한 칸 띄운 뒤,
   monoDown 폴더 안의 install-mac.command 파일을 터미널 창으로 끌어다 놓고 Enter.
   - 1~3분 정도 걸립니다. 관리자 비밀번호는 필요 없습니다.
   - "✅ 설치 완료"가 나오면 끝입니다.

4. 프리미어 프로를 완전히 종료(⌘Q)했다가 다시 켜고
   창 > 확장 > monoDown 을 엽니다.

5. 패널 맨 아래에 v1.3.1 과 "yt-dlp ✓ ffmpeg ✓ deno ✓" 가 보이면 정상입니다.

업데이트
- 새 버전은 패널을 열 때 자동으로 적용됩니다. 다시 설치할 필요 없습니다.
- 바로 확인하려면 패널 아래 "업데이트 확인"을 누르세요.

문제 해결
- 메뉴에 monoDown이 없음: 프리미어를 완전히 종료 후 다시 실행. 그래도 없으면 3번을 다시 실행.
- ✗ 표시가 있음: 3번을 다시 실행.
- 다운로드 실패(403 등): 패널이 자동으로 재시도합니다. 계속 실패하면 잠시 후 다시 시도하세요.
